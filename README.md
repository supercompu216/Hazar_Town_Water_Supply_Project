# Hazara Town Water Supply Project Dashboard

A single-page dashboard built from an Urdu news article about the Hazara Town (Quetta) water supply project.

## Features
- Photo background with colored summary cards
- Light/dark theme switch and five accent colors
- Voice assistant: read the full Urdu article aloud (Web Speech API), pause/resume/stop, speed and voice selection, per-paragraph playback
- Voice commands (Urdu or English): read, stop, pause, resume, dark, light, color names

## Files
- `index.html` - the whole app (HTML, CSS, JS)
- `assets/background.jpg` - background image

## Run locally
Open `index.html` in a browser. Voice input works best in Chrome or Edge; Urdu speech output needs an Urdu voice installed on the device.

## Publish with GitHub Pages
1. Push these files to a GitHub repository.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

Note: the browser microphone requires HTTPS, which GitHub Pages provides.
